# 网页视频截图

一个零依赖的 Chrome / Edge 扩展，支持哔哩哔哩视频以及抖音 Web 版视频、图文。点击扩展按钮或按 `Alt+Shift+S`，会在不暂停播放的情况下截取当前视频画面；检测到抖音图文时，则直接下载当前展示的图片资源，保留其分辨率和图片格式。

## 安装

1. 打开 Chrome 的 `chrome://extensions/`（Edge 为 `edge://extensions/`）。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目目录。
4. 打开哔哩哔哩或抖音视频页面。

## 使用

- 点击浏览器工具栏中的扩展图标；或
- 按 `Alt+Shift+S`（可在 `chrome://extensions/shortcuts` 修改）。

截图会按平台保存到默认下载目录下的 `Bilibili截图` 或 `抖音截图` 文件夹。当前实现只截取屏幕中实际可见的视频区域；若视频有一部分超出窗口，建议先进入网页全屏或浏览器全屏。

## 隐私

扩展仅在用户主动点击或使用快捷键时读取当前哔哩哔哩或抖音标签页画面。它不发送网络请求，也不会上传截图。

## 测试

项目使用 Node.js 内置测试工具，无需安装依赖：

```sh
node --test
```
